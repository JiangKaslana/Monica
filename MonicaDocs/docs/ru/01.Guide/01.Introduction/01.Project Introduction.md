`Monica` — это локальный менеджер паролей (Local Vault), объединяющий экосистемы **Bitwarden** и **KeePass**.
Построенный на архитектуре local-first, он помогает унифицированно управлять учётными записями, паролями, 2FA-токенами, приватными заметками и конфиденциальными вложениями на Android и в браузерах.

::: info 📌 Объявление о статусе проекта
- **Monica for Windows** заархивирован. Исторический код: [`Monica-for-Windows`](https://github.com/JoyinJoester/Monica-for-Windows)
- :hourglass_flowing_sand: Из-за ограниченных ресурсов разработки, `Monica for Wear` и `Monica-for-Extension` временно **не обновляются активно**.
- :dart: На данном этапе все усилия сосредоточены на доработке функциональности, оптимизации UX и поддержании стабильности **`Monica Android`**. Спасибо за понимание.
Приглашаем сообщество к участию!
:::

## 🧭 Руководство пользователя

### 🎯 Для кого Monica
- [x] Пользователи, предпочитающие **локальное хранение** и не желающие размещать учётные данные на сторонних облачных серверах.
- [x] Пользователи двух экосистем — **Bitwarden** и **KeePass** (`.kdbx`).
- [x] Те, кому нужна эффективная работа на Android и **интеллектуальный автозаполнитель** в браузере.

### 🎁 Что вы получаете
- **Локальное шифрованное хранилище**: учётные данные, банковские карты, документы, заметки, вложения.
- **Агрегация двух экосистем**: Bitwarden API/синхронизация + чтение/запись KeePass (`.kdbx`) на Android.
- **Разнообразная синхронизация/резервирование**: безопасная передача данных между устройствами через собственный <mark>WebDAV</mark>.
- **Встроенный TOTP**: управление паролями и кодами двухфакторной аутентификации в одном приложении.

## 📱 Ключевые особенности Android

### ✨ Основные функции
- **Локальное хранилище** <Badge text="Безопасность данных" type="tip"/> — все учётные данные шифруются локально с высокой стойкостью.
- **Агрегированный импорт** <Badge text="Мульти-экосистема" type="info"/> — полная поддержка миграции из KeePass и совместимость с Bitwarden.
- **Умный поиск** <Badge text="Эффективность" /> — многомерный поиск по названию, домену, тегам.
- **Биометрическая аутентификация** <Badge text="Удобство" /> — интеграция с системной биометрией (отпечаток/лицо).
- **Управление TOTP** <Badge text="2FA" type="warning"/> — унифицированное хранение и динамическая генерация кодов двухфакторной аутентификации.

### 🛠️ Технический стек

| Уровень архитектуры | Технологии и компоненты |
| :--- | :--- |
| **UI** | `Jetpack Compose` + `Material 3` + `Navigation Compose` |
| **Хранение данных** | `Room` (`PasswordDatabase`) + DAO + Repository |
| **Асинхронность** | Kotlin `Coroutines` + `Flow` |
| **DI** | `Koin` (инициализация в `MonicaApplication`) |
| **Фоновые задачи** | `WorkManager` (`AutoBackupWorker` для автоматического WebDAV-резервирования) |
| **Протоколы и интеграции** | `Retrofit` + `OkHttp` (Bitwarden API)<br>`kotpass` (ядро KeePass)<br>`sardine-android` (клиент WebDAV) |

### 🔒 Модель безопасности

> [!NOTE]
> **1. Основной алгоритм шифрования**
> **`AES-256-GCM`** — аутентифицированное шифрование, обеспечивающее конфиденциальность и целостность данных, защиту от подделки.

> [!NOTE]
> **2. Механизм派生ения ключей**
> **`PBKDF2-HMAC-SHA256`** с высокими параметрами итераций — значительно повышает стоимость оффлайн-атак перебором и радужных таблиц.

> [!NOTE]
> **3. Аппаратная защита**
> Хеш мастер-пароля и конфигурации безопасности управляются **`Android Keystore`**, **`EncryptedSharedPreferences`** и **`BiometricPrompt`**. Ключи не покидают аппаратную зону безопасности.

> [!CAUTION]
> **4. Явные сетевые границы**
> Сетевые разрешения используются **исключительно** для Bitwarden API, WebDAV-резервирования и синхронизации, инициируемых пользователем. Никакого стороннего трекинга или скрытой аналитики.
